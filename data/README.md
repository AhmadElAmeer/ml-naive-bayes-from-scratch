# Data: SMS Spam Collection v.1

`sms.tsv` holds 5,574 English SMS messages labelled `ham` (4,827) or `spam` (747), one per line as `label<TAB>message`.

**Source:** Tiago A. Almeida and José María Gómez Hidalgo, *SMS Spam Collection v.1*, published through the UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/228/sms+spam+collection

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0), as listed by the UCI repository. The data is included unchanged, except for the file name and the `.tsv` extension.

**Citation:** Almeida, T.A., Gómez Hidalgo, J.M., Yamakami, A. *Contributions to the Study of SMS Spam Filtering: New Collection and Results.* Proceedings of the 2011 ACM Symposium on Document Engineering (DOCENG'11), Mountain View, CA, USA, 2011.

Some spam messages in the dataset contain adult content, as real SMS spam often does.
